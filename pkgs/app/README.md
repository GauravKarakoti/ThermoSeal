# ThermoSeal dApp — Frontend

Frontend interface for ThermoSeal on the Midnight Network (PreProd), built for live commercial cold-chain tracking and verification[cite: 1].

## Commercial & Live User Features

* **Live Shipment Telemetry:** Real-time visibility into active transport legs, verified chunk counts, and compliance statuses.
* **Lace Wallet Integration:** Seamless connection via `window.midnight.mnLace` for secure cryptographic signing.
* **Bilingual Support:** Instant toggling between English and Hindi for regional logistics operators.

## Technical Stack

* **Framework:** React 19 + TypeScript
* **Build Tool:** Vite 8
* **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
* **UI Components:** shadcn/ui + Lucide React
* **Internationalization:** i18next 26 + react-i18next 17
